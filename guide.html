⚡ WELCOME TO CYBERPUMP

CYBERPUMP is a mobile workout tracking application designed for maximum flexibility. You can build custom training routines from scratch using our Web Builder or in-app editor, or import pre-made JSON workout templates directly to start training immediately.

🏋️‍♂️ STANDARD REP-BASED EXERCISES

Standard exercises are structured around sets, reps, and defined rest periods. CYBERPUMP acts as your automatic training assistant.

  • ✅
    Execution & Set Completion: Perform your set with the targeted weight and reps, then tap Complete Set. CYBERPUMP logs the set and automatically triggers your rest timer.
  • 👀
    Next Exercise & Set Preview: During recovery, CYBERPUMP displays a prominent Next Up preview banner telling you exactly which exercise, set number, weight, and target reps are coming up next, so you can prepare your equipment ahead of time.
  • ➕
    On-The-Fly Controls: Need extra recovery time? Tap +10s to extend the rest. Tap Skip Rest to jump straight to the next set.

⏱️ TIME-BASED EXERCISES & INTERVALS

For isometric holds, HIIT, or timed intervals, CYBERPUMP manages active work duration and recovery periods completely hands-free.

  • ⏳
    Active Work Countdown: CYBERPUMP counts down your active work interval. When time reaches 0s, it automatically moves to your recovery timer.
  • 🚫
    Rest Set to 0 Seconds: If rest is configured to 0s for a time-based exercise, the next interval or exercise starts immediately without stopping to confirm.
  • 🤖
    Hands-Free Automation: Interval rounds auto-advance sequentially so you never have to touch your phone during high-intensity training.

⚡ TRANSITIONS & AUTO-START OPTION

Control how CYBERPUMP moves from one exercise to the next in your routine.

  • 🛑
    Manual Confirmation Screen (Auto-Start OFF): When completing an exercise, CYBERPUMP displays a Get Ready screen showing the next exercise, target reps, and weight. Tap Start Next Exercise when you are ready.
  • ⚡
    Auto-Start Enabled (Skip Confirmation): Enable ⚡ Auto-start on an exercise to skip the confirmation screen entirely. The next exercise starts instantly—ideal for warm-up flows, mobility drills, or seamless supersets where every exercise must follow immediately without user input.

🔄 CIRCUIT EXECUTION MODE

Switch your entire workout into a continuous circuit structure with dedicated cycle rest intervals.

  • 🔄
    Sequential Cycling: In Circuit Mode, you run through exercise 1, then exercise 2, then exercise 3 sequentially for your chosen number of cycles (e.g. 3 cycles).
  • 🔔
    Rest Between Full Cycles: You can set short rest periods between individual exercises and a longer dedicated recovery break (e.g. 90s) between full circuit cycles. During cycle rest, CYBERPUMP previews the first exercise of the upcoming cycle.

⚡ PUMP OVERDRIVE MODE

An optional high-energy visual and audio theme for maximum intensity training sessions.

  • ⚡ High-Intensity Focus: Activates an energetic visual pulse and high-contrast HUD to keep you locked into high-density training sessions.
  • 🔊 Adaptive Audio Signals: Provides acoustic feedback and interval cues aligned with your active app mode and sound settings.
